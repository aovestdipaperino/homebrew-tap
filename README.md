# homebrew-tap

Homebrew tap for tools by [aovestdipaperino](https://github.com/aovestdipaperino).

## Install

```sh
brew tap aovestdipaperino/tap
brew install aovestdipaperino/tap/<formula>
```

## Formulae

| Formula | Description |
|---|---|
| `tokensave` | Code intelligence tool that builds semantic knowledge graphs from source code |
| `tokensave-beta` | Beta channel of tokensave |
| `plank-agent` | Interactive coding agent with a terminal REPL (macOS) |
| `plank-agent-beta` | Beta channel of plank (macOS) |
| `bruto-pascal` | TUI-based Mini-Pascal IDE with LLVM-backed compiler and lldb debugger |
| `seb` | Render mermaid diagrams to SVG, byte-identical to mermaid-cli, no browser |
| `oronzo` | A toolkit for Claude Code sessions |
| `tdk` | Turbo Vision debug console for live token streams |
| `turbo-debug-console` | Turbo Vision debug console for live token streams |

Formula versions are bumped when the corresponding project cuts a release. For Windows, see [scoop-bucket](https://github.com/aovestdipaperino/scoop-bucket).
